# 💻 HanS-Plan AI: 맞춤형 비교과 큐레이션 및 정렬 로직 프롬프트 기록

**작업자:** 김진오
**작업 기간:** 2026-05-23
**구현 목표:** 팀원이 만든 온보딩 데이터와 연동해서, 맞춤형 비교과 프로그램을 가성비/포인트 순으로 정렬해 보여주는 캘린더 화면 만들기

---

### 1단계: 정렬/추천 기능 따로 분리하기 (깃허브 충돌 방지)
* **작업 의도:** 팀원이 `app.py`에 프로필 데이터를 저장해 뒀는데, 내가 캘린더 화면 코드를 짤 때 팀원 코드랑 엉켜서 깃허브 Merge 충돌이 나지 않도록 핵심 정렬 로직만 따로 파일로 빼서 만들려고 함.
* **입력 프롬프트:** > "현재 팀원이 온보딩 데이터를 `st.session_state`에 저장해 뒀어. 나는 이걸 받아서 프로그램들을 정렬하는 역할을 맡았는데, 팀원 코드랑 안 겹치게 `utils/recommender.py` 파일에다가 판다스(Pandas)로 관심 분야를 필터링하고 정렬(포인트 높은 순, 가성비 순 등)해 주는 함수를 따로 분리해서 짜줘."
* **결과:** 판다스를 활용해 조건에 맞게 데이터를 걸러내고 정렬해 주는 `get_sorted_programs` 함수 작성 완료.

### 2단계: 화면(UI) UI 만들기 및 더미 데이터로 테스트
* **작업 의도:** 아직 팀에서 쓸 전체 비교과 CSV 데이터 파일이 완성되지 않아서, 내 화면(UI)이 잘 작동하는지 테스트하기 위해 파이썬 코드 안에 더미 데이터를 넣어서 우선 확인해 보기 위함.
* **입력 프롬프트:**
  > "아직 `programs.csv` 파일이 없는데 화면이 잘 나오는지 먼저 테스트해보고 싶어. `pages/1_Calendar.py` 코드 안에 파이썬 딕셔너리로 임시 더미 데이터(Mock Data)를 몇 개만 넣어주고, 스트림릿(Streamlit) 라디오 버튼을 눌렀을 때 아까 만든 정렬 함수가 작동해서 표가 화면에 나오게 코드를 짜줘."
* **결과:** 온보딩 세션 정보를 제대로 받아오는지 확인하는 로직과, 더미 데이터를 활용한 캘린더 정렬 화면 뼈대 완성.

### 3단계: 표 안 나오는 에러 해결 (디버깅)
* **작업 의도:** 데이터 필터링은 되는데 화면에 표가 안 뜨는 에러가 발생해서, 파이썬 내부에서 어디가 문제인지 파악하고 고치기 위함.
* **입력 프롬프트:**
  > "코드를 돌려보니까 추천 리스트 제목만 나오고 밑에 표가 텅 비어서 안 나와. 어디서 데이터가 증발했는지 확인하게 중간중간 상태를 프린트해 주는 디버깅 코드를 추가해 줄래? (디버깅 확인 후) 데이터는 잘 살아있는데 스트림릿에서 표를 그릴 때 충돌이 나는 것 같아. 안 깨지고 확실하게 표를 띄워주는 명령어로 교체해 줘."
* **결과:** 디버깅 코드로 로직 자체는 잘 돌아간다는 걸 확인했고, 표를 그리는 명령어를 `st.dataframe`에서 윈도우 환경 충돌이 적은 `st.table`로 바꿔서 화면에 표가 잘 나오도록 에러 해결함.

### 4단계: 제출용 최종 코드 정리
* **작업 의도:** 에러를 고치면서 지저분해진 디버깅 코드들을 지우고, 깃허브에 올리기 위해 깔끔하게 코드 정리.
* **입력 프롬프트:**
  > "표 안 나오는 문제가 완벽하게 해결됐어! 이제 화면 테스트하려고 넣었던 파란색 디버깅 알림창 코드들은 싹 다 지워주고, 다른 팀원들이 보기 편하게 주석 달아서 최종 완성본으로 `1_Calendar.py` 전체 코드를 다시 정리해 줘."
* **결과:** 불필요한 테스트 코드를 지우고 주석이 깔끔하게 정리된 최종 캘린더 화면 파일 완성.

### 5단계: 시각적 최적화 캘린더 (슬롯 디자인 & 동적 필터링) 도입
* **작업 의도:** 기획서에 명시된 '구겨진 달력의 시각적 과부하 탈피'를 위해 기존의 딱딱한 표(`st.table`) 형식을 버리고, 트렌디한 카드(슬롯) 레이아웃과 클릭형 카테고리 필터링을 도입하여 사용자 경험(UX)을 극대화함.
* **입력 프롬프트:**
  > "이전에 만든 표 형식의 캘린더를 기획서의 '시각적 최적화 슬롯' 형태로 완전히 업그레이드하고 싶어. 스트림릿의 라디오 버튼을 활용해 화면 상단에 '전체보기', '창의융합', '봉사' 같은 분야별 필터 버튼을 가로로 만들어 줘. 그리고 그 버튼을 누를 때마다 밑에 뜨는 데이터들이 표가 아니라, `st.container(border=True)`를 활용해서 제목, 일정, 포인트가 한눈에 들어오는 깔끔한 카드(슬롯) 형태로 세로로 나열되도록 코드를 리팩토링해 줘."
* **결과:** 스트림릿의 컬럼 레이아웃(`st.columns`)과 컨테이너를 조합하여 정보 가독성이 뛰어난 Focus Mode 형태의 슬롯 캘린더 뷰 완성. 필터링 버튼 클릭 시 즉각적인 렌더링 반응 확인.
