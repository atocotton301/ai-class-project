입력 프롬프트:

"마이페이지에서는 본인이 입력한 정보를 볼 수 있으면 좋겠어. 그리고 프로필 수정 기능도 같은 화면에 있으면 좋겠어."

수정 폼 렌더링 시 기존 데이터베이스의 값을 value 및 default 파라미터로 자동 바인딩하여, 빈 폼을 다시 채워야 하는 불편함을 제거(Context Preservation 디자인 적용).
